### 1) Partner logo carousel (auto-scrolling)
- A seamless, **infinite horizontal marquee** of logos from `partners` where `showInCarousel === true`.
- Heading **"Our partners"** with subline *"Backed by brands who believe in People. Padel. Places."*
- Logos in muted **greyscale that colourises on hover**; consistent height and padding; **pause on hover**; slow, smooth, seamless loop (duplicate the list so there's no visible jump); links open in a new tab (`rel="noopener noreferrer"`).
- **Accessibility:** if `prefers-reduced-motion` is set, don't animate — show a static, wrapped logo row instead.
- Place it near the foot of the homepage, with a quiet **"Partner with us →"** link to `/partner-with-us`.
- If there are no carousel partners yet, show one elegant line: *"Partnership spots open — [Partner with us]."*

### 2) Website advertising slots (scheduled, tasteful)
- Build an `AdSlot` component that, given a slot name, shows the **currently-active** advert(s) for that slot — i.e. where today's date is between `start` and `end`. If several are active, **rotate** them (fade every ~8s); if none, render nothing (collapse the space — never show an empty or broken slot).
- Each rendered advert: the brand creative (use `creativeLight`/`creativeDark` per background; if missing, show the advertiser name in a styled text lockup), optional headline, a clear clickable area (new tab, UTM link), and a small, legally-required label **"In partnership with"** or **"Advertisement"** in muted text.
- Slots to place (keep density low — max one visible per screen):
  - `home-banner` — one refined placement above the footer on the homepage.
  - `events-inline` — a single placement on the events page.
  - `sidebar` — optional, only if the layout has a sidebar.
- Design them as premium framed cards that match the site — **not** loud banners. No pop-ups, no autoplay video, no more than one accent colour.

### 3) Event sponsors (keep/confirm)
- Each event page/card shows a subtle **"Supported by"** row of that event's `sponsors` logos.

### Tracking (ROI evidence for advertisers & sponsors)
- Every partner/advert/sponsor outbound link carries UTM params and fires a lightweight event to analytics (GA4/Plausible if present; else `console.log` a `partner_click` / `advert_click` event with the name).
- For adverts, also log an **impression** event when the slot renders, so we can report impressions + clicks per advertiser.

### "Partner with us" page (`/partner-with-us`) — update
- Present **three ways to partner**, each with a one-liner and a "By arrangement" note (no fixed prices):
  1. **Event Sponsorship** — back a specific event; on-court and on-page branding, tickets, an "Exchange" slot.
  2. **Website Advertising** — an always-on brand placement reaching our community (great for padel & lifestyle brands).
  3. **Founding Partner** — headline, ongoing, top billing in the carousel and across the site.
- Keep the audience-snapshot stat tiles (editable placeholders) and the **enquiry form** (name, company, work email, interest dropdown covering the three options, message, GDPR consent). No payment — store the enquiry and email the organiser.

### Rules
- **Never** expose member/registration data on any public sponsor/advert surface — cohort access is separate and opt-in/aggregate only.
- Data-driven and easy to edit; missing images fall back to a styled text lockup, never a broken image.
- Add "Partners" to nav + footer.
- After building, show me: the homepage with the carousel and `home-banner` advert, the `/partners` page, and `/partner-with-us`, on desktop and mobile.
